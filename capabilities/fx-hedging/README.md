# FX Hedging

Comparing ways to hedge a foreign-currency receivable: forward contracts, money-market hedges, and currency options.

## Files
- `spec.md`: model specification (Stage 2, complete): named-range inputs, tab architecture, calculation flow, sensitivity plan, and validation rules.
- `model.xlsx`: hedge comparison workbook (Stage 3, upcoming), built from `spec.md`.

- offshore-wind-cable: hedging a EUR 16,000,000 receivable due in 12 months (in progress; Stage 2 complete)
