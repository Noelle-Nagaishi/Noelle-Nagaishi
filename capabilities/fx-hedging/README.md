# FX Hedging

Comparing ways to hedge a foreign-currency receivable: forward contracts, money-market hedges, and currency options.

## Files
- `spec.md`: model specification (v1.2): named-range inputs, tab architecture, calculation flow, sensitivity plan, and validation rules.
- `model.xlsx`: hedge comparison workbook (Stage 3, complete), built from `spec.md` v1.2; all 20 validation checks pass at the base case.
